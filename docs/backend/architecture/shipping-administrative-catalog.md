# Shipping administrative catalog

The canonical source is `src/WorkspaceEcommerce.Infrastructure/Shipping/Data/vietnam-administrative-catalog.json`.
It is embedded in Infrastructure and consumed through `IShippingAdministrativeCatalog`.
The storefront file is generated by `node scripts/generate-shipping-catalog.mjs`;
`--check` verifies that the generated artifact still matches the source bytes.
Do not edit the generated TypeScript or keep a separate hand-maintained list.

## Provenance

Version `VN-QD19-2025-NQ237-2026-v1` uses the code/name annexes of
[Decision 19/2025/QD-TTg, Official Gazette volumes 919–922](https://congbao.chinhphu.vn/van-ban/quyet-dinh-so-19-2025-qd-ttg-45430.htm).
The complete province/ward code-parent sets were extracted from both official
volumes and compared against the previous repository dataset. The difference
for Ba Che is corrected to `06970` under province `22`; `06978` is not accepted
as a canonical alias. No stored historical addresses are rewritten.

The ten Dong Nai ward type changes follow
[Resolution 237/NQ-UBTVQH16](https://chinhphu.vn/?classid=0&docid=217876&pageid=27160),
and the provincial type follows
[Resolution 30/2026/QH16](https://vanban.chinhphu.vn/?classid=1&docid=218009&pageid=27160).
These changes preserve codes. Gazette spelling is retained for other labels.
Source pages were checked on 2026-10-29. This is a pinned, auditable dataset,
not a claim of live synchronization with future administrative changes.

The pinned artifact contains 34 province-level entries and 3,321 ward-level
entries. These counts describe this version only. Runtime coverage is derived
from the catalog and code-parent validation, never these numeric constants.
Province-level zone membership includes wards and special administrative units;
no unconfigured island surcharge or silent postcode-based exclusion is added.

## Updates and compatibility

Verify an official source, bump the catalog version, update this provenance,
regenerate TypeScript and run catalog/coverage tests. Publish a new complete rate
plan using the new version; never rewrite a published plan or historical order.
Names are display/provider mapping values, not identifiers. Leading zeroes are
significant. The later quote contract sends province and ward codes; existing
checkout still sends its existing name fields until SHIP-06/07.

Do not silently normalize arbitrary legacy codes/names. If an old client has
Ba Che `06978`, require a fresh catalog selection for new code-based quotes.
Historical snapshots remain as recorded. Old and new catalog versions must be
handled explicitly during a rolling deployment; a mixed-version admin operation
is rejected rather than publishing partial nationwide coverage.
